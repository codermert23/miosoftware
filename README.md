# MIO Software

Oyun ve mobil uygulama geliştiricisi MIO Software'in kişisel web sitesi: [miosoftware.org](https://miosoftware.org)

Saf HTML, CSS ve JavaScript ile yazılmış statik bir site. Derleme adımı yok, GitHub Pages üzerinden yayınlanıyor.

## Yapı

| Dosya | Açıklama |
| --- | --- |
| `index.html` | Ana sayfa ve projeler |
| `hakkimda.html` | Hakkımda |
| `iletisim.html` | İletişim ve form |
| `404.html` | Bulunamayan sayfalar |
| `assets/js/projects.js` | Proje listesi. Yeni proje eklemek için buraya bir nesne ekle. |
| `assets/css/style.css` | Tüm stiller |
| `design/DESIGN.md` | Tasarım sistemi |

## Yerelde çalıştırma

```bash
python -m http.server 8000
```

Ardından tarayıcıda `http://localhost:8000` adresini aç.
